+----------------------------+-----------------------------------------------------------------------------------------------------------------------------------------+

| Recurso / Componente       | Descrição / Característica Principal                                                                                                    |
+----------------------------+-----------------------------------------------------------------------------------------------------------------------------------------+

| WAF & Security Zones       | Protege aplicações web contra ataques maliciosos como SQL Injection e Cross-Site Scripting.                                             |
+----------------------------+-----------------------------------------------------------------------------------------------------------------------------------------+

| Security List              | Componente responsável por controlar o tráfego entre subnets dentro de uma VCN através de regras de entrada e saída.                    |
+----------------------------+-----------------------------------------------------------------------------------------------------------------------------------------+

| Budgets                    | Monitora e controla os gastos com serviços do OCI enviando alertas personalizados.                                                      |
+----------------------------+-----------------------------------------------------------------------------------------------------------------------------------------+

| Block Volume               | Tipo de armazenamento associado a instâncias Compute, possuindo a feature Online Resizing para aumentar o tamanho do disco.             |
+----------------------------+-----------------------------------------------------------------------------------------------------------------------------------------+

| Oracle Roving Edge         | Infraestrutura que opera de forma isolada (Edge computing) e não possui múltiplos provedores de nuvem vinculados.                      |
+----------------------------+-----------------------------------------------------------------------------------------------------------------------------------------+

| Object Storage Tiers       | Camadas: Standard (Acesso imediato, Hot), Infrequent Access (Acesso rápido, retenção mínima 31 dias) e Archive (Raro, mínima 90 dias). |
+----------------------------+-----------------------------------------------------------------------------------------------------------------------------------------+

| OCI File Storage           | Serviço de armazenamento de arquivos gerenciado que utiliza nativamente o protocolo NFS.                                                |
+----------------------------+-----------------------------------------------------------------------------------------------------------------------------------------+

| Cloud Guard                | Monitora continuamente recursos e configurações para detectar problemas, remediar riscos e manter uma postura de segurança forte.       |
+----------------------------+-----------------------------------------------------------------------------------------------------------------------------------------+

| Security List vs. NSG      | A Security List aplica-se a toda a subnet, enquanto o Network Security Group (NSG) aplica-se a instâncias individuais.                  |
+----------------------------+-----------------------------------------------------------------------------------------------------------------------------------------+

| Route Table                | Define as regras para tráfego de subnets para destinos fora da VCN, direcionando o tráfego de rede para o destino correto.              |
+----------------------------+-----------------------------------------------------------------------------------------------------------------------------------------+

| OCI Load Balancer          | Suporta 3 algoritmos: Round Robin (distribui o tráfego uniformemente), Least Connections e IP Hash.                                     |
+----------------------------+-----------------------------------------------------------------------------------------------------------------------------------------+

| Live Migration             | Recurso do OCI Compute que permite migrar instâncias ativas entre Fault Domains diferentes com zero downtime.                           |
+----------------------------+-----------------------------------------------------------------------------------------------------------------------------------------+

| Compartment Quotas         | Políticas aplicadas por compartimento que permitem definir limites físicos de uso de recursos para governança corporativa.              |
+----------------------------+-----------------------------------------------------------------------------------------------------------------------------------------+

| Principal (IAM Policy)     | Componente de uma política do IAM que define o usuário ou o grupo de usuários ao qual as permissões serão aplicadas.                    |
+----------------------------+-----------------------------------------------------------------------------------------------------------------------------------------+

| Cost Analysis              | Ferramenta que permite visualizar, analisar graficamente e entender os padrões de consumo e gastos ao longo do tempo.                    |
+----------------------------+-----------------------------------------------------------------------------------------------------------------------------------------+

| Compartments               | Recurso global estruturado em hierarquia para organizar recursos; o gerenciamento de chaves e segredos é feito pelo OCI Vault.           |
+----------------------------+-----------------------------------------------------------------------------------------------------------------------------------------+

| OCI Dedicated Region       | Solução que permite aos clientes implantar uma região inteira da nuvem Oracle dentro de seu próprio data center físico.                |
+----------------------------+-----------------------------------------------------------------------------------------------------------------------------------------+

| LB vs. Network LB          | O Load Balancer opera na camada de aplicação (Camada 7) e o Network Load Balancer opera na camada de transporte (Camada 4).             |
+----------------------------+-----------------------------------------------------------------------------------------------------------------------------------------+

| Instance Configuration     | Configuração predefinida (contendo shape, imagem base e metadados) usada para automatizar a criação de instâncias idênticas.             |
+----------------------------+-----------------------------------------------------------------------------------------------------------------------------------------+
